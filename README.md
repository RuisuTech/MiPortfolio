# Jose Luis Guzman — Portafolio Web

Portafolio web profesional desarrollado con **React 19**, **TypeScript**, **Tailwind CSS 4** y **Vite 6**.

## Tecnologías

- **Frontend:** React 19, TypeScript, Tailwind CSS 4, Vite 6
- **Componentes:** Lucide React (iconos)
- **Tests:** Vitest + React Testing Library
- **Estilo:** Dark/Light theme con variables CSS

## Estructura

```
src/
├── components/       # Componentes UI modulares
├── data/             # portfolioData.ts (datos centralizados)
├── types.ts          # Interfaces TypeScript
├── App.tsx           # Componente principal
├── main.tsx          # Entry point
└── index.css         # Estilos globales y Tailwind
public/
├── assets/mockups/   # Imágenes de proyectos
└── CV_Jose_Luis_Guzman.pdf
```

## Instalación

```bash
git clone https://github.com/RuisuTech/jose-luis-guzman-_-portafolio-web---ruisutech.git
cd jose-luis-guzman-_-portafolio-web---ruisutech
npm install
npm run dev
```

Abre http://localhost:3000

## Scripts

- `npm run dev` — Servidor de desarrollo
- `npm run build` — Build para producción
- `npm run preview` — Vista previa del build
- `npm run lint` — Verificación de código
- `npm run test` — Ejecutar tests
- `npm run test:run` — Tests en modo single-run
